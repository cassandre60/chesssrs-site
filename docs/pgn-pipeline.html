PGN & Study Ingestion Pipeline

Multi-chapter PGN parsing, recursive annotation variation (RAV) preservation, move canonicalization, and quality quarantine.

Source in app repo: docs/pgn-import.md
App version: v1.4.0
Licence: GPL-3.0

1. Input Sources & Ingestion

ChessSRS accepts opening material through two primary avenues:

  • Standard PGN Files & Text: Direct file picker (.pgn) or clipboard paste supporting multi-game collections, extensive comments, and deeply nested sub-variations.
  • Lichess Study Import: Enter any public Lichess study URL or 8-character study ID (e.g. https://lichess.org/study/Gg4E2sIS). For private or unlisted studies, users can sign in with their Lichess account via OAuth Bearer token to import their private repertoires.

2. AST & Recursive Variation Tree Parsing

A PGN study is parsed into an Abstract Syntax Tree (AST) using dartchess's streaming parser:

  • Multi-Game Streams: Each PGN game block (separated by standard PGN header tags) is mapped to an independent Chapter within the parent Study.
  • Recursive Annotation Variations (RAV - INV-010): Sibling variations wrapped in parentheses ( ... ) are preserved down to arbitrary depth. Branches are never flattened or pruned.
  • Numeric Annotation Glyphs (NAGs): Evaluative symbols ($1 = !, $2 = ?, $3 = !!, $4 = ??, etc.) are parsed into node metadata.
  • Author Annotations: Explanatory text comments embedded in curly braces { ... } are stored with the position node and displayed to the user after recall attempts (configurable in Settings).

3. Move Validation & FEN Normalization

Imported moves must undergo rigorous geometric validation:

  1. Legality Verification: Every move is executed on an internal dartchess.Position instance. Illegal moves, ambiguous algebraic notation, or invalid castling rights trigger immediate quarantine.
  2. Coordinate Conversion: Standard Algebraic Notation (SAN: e.g. Nf3, O-O) is resolved into canonical UCI coordinates (e.g. g1f3, e1g1).
  3. Side Determination: The parser analyzes branch structures to automatically detect whether the chapter trains White or Black lines.

4. Quality Gates & Error Quarantine

INV-011 Malformed Input Quarantine

If a PGN file contains syntax corruption, illegal moves, or truncated bodies, the invalid chapters are quarantined with specific line and character error diagnostics. Valid chapters are cleanly imported; an import is never left in a corrupt, half-applied state.

INV-003 Duplicate Import Rejection

Importing a PGN whose canonical tree hash matches an already imported study switches directly to that study. It never inserts duplicate studies, chapters, or duplicate decision cards in SQLite.
