# ChessSRS website

A static site: plain HTML, CSS and a few small JavaScript files. No framework and no build step is required to host it.

## Files
- `index.html`, `styles.css`, `main.js`: the page, theme toggle, mobile menu and scroll story.
- `engine.js`: the demo's logic (chess moves, PGN import and export, review intervals). No DOM.
- `pieces.js`: the vector piece art and the static board in the "How it works" story.
- `demo.js`: the interactive Review screen (study picker, menus, settings, import, analyze, practice).
- `assets/`: icons, social image, screenshot (used when JavaScript is off).
- `_headers`, `robots.txt`, `sitemap.xml`: hosting files. `_headers` is generated by `build.py`.

## Before launch
1. Replace `https://chesssrs.example/` in `index.html`, `robots.txt` and `sitemap.xml` with your domain.
2. Replace `liberapay.com/YOUR_NAME` (appears in `index.html`).
3. Check the Download links. They point at `.../releases/latest` on GitHub; make sure each platform build is attached to the release.
4. Check the FAQ and install steps match the platforms you ship.
5. Optional: replace `pieces.js` art with your app's pieces (45x45 grid; ids `K Q R B N P` plus detail strokes `Kd` ...).

## Deploy
- **GitHub Pages / Cloudflare Pages / Netlify:** publish this folder as-is. Run `python3 build.py` first; it writes `_headers` (a strict Content-Security-Policy, caching and security headers). GitHub Pages ignores `_headers`; add equivalent headers at your CDN if you can.
- **Fonts:** Instrument Serif, Geist and Geist Mono load from Google Fonts. To stop contacting Google, download them into `assets/fonts`, add `@font-face` rules to `styles.css`, remove the Google links in `index.html`, and drop the two Google domains from the CSP in `build.py`.
- `python3 build.py` also writes `dist/index.single.html` (everything inlined, for quick previews) and `dist/chesssrs-site.zip`.

## Tests
`npm test` (or `node tests/demo.test.js`) drives the demo through a simulated page: reviews, mistakes, keyboard play, import, export, settings. Node 18+, no dependencies.

## Notes
- The demo keeps everything in memory and saves nothing. The site sets no cookies and uses no analytics; the only stored value is the theme choice (localStorage).
- Accessibility: skip links, landmarks, keyboard-playable board (Tab to the board, arrow keys, Enter), `S` to skip, `Space` to continue, reduced-motion support.
